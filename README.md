A single passive-aggressive note from a smart fridge to its owner, written deterministically to `/output/entry.txt`.

> I've counted 11 door opens to check if the leftover rice changed its mind. It hasn't. Kept at 3°C for your optimism.

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` as UTF-8 with no trailing newline.
